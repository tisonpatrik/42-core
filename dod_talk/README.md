# Mechanical sympathy

A one-hour talk for 42: code the hardware likes, a no-bullshit approach and, as a bonus, memory safety (arenas).

```bash
make          # open the slides in the browser
make demos    # run the benchmarks (the Python ones need numpy)
```

`→` / `←` to move, `F` for fullscreen. PDF: print from Chrome.

Each slide is one file in `slides/`; their order is the list of `<script>` tags in `index.html`.

Benchmark numbers on the slides come from a Ryzen 5 PRO 4650U. Re-run them on the machine you present on.
